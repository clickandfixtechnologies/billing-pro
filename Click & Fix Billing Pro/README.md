# Click & Fix Billing Pro

Sprint 1 / Milestone 1.1 — local SPA foundation.

## Run locally

Open `index.html` in a modern browser. For the most reliable IndexedDB behaviour, use a local static server (for example, VS Code Live Server).

## Included

- Responsive single-page application shell
- Navigation for all planned modules
- IndexedDB database `ClickFixBillingDB`
- Core stores, auto-number counters, and audit-log support
- Dashboard reading live local database counts

Google Drive sync, customer CRUD, invoices, PDFs, backups, reminders, and inventory workflows are intentionally not implemented in this foundation milestone.
